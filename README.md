# Vrij-lezen-op-maat-POC
Proof of Concept voor 'Vrij lezen op maat' — een webapp die studenten op basis van een persoonlijk leesprofiel onderbouwde leesadviezen geeft, met catalogus, leeslijst en docentkoppeling. Full-stack, componentgebaseerd, met JWT-auth en gecombineerde relationele/document-dataopslag.
